# WebSlim

WebSlim is a web optimization and analysis tool built to identify unused JavaScript and CSS resources in websites. The project uses Puppeteer and Chrome Coverage API to analyze frontend resource usage and provide insights about possible optimizations.

The main idea behind the project is to help developers understand how much unnecessary code is being loaded on websites and how reducing it can improve performance and resource efficiency.

## Features

- Detects unused JS and CSS
- Generates optimization reports
- Estimates possible resource savings
- Provides basic performance insights
- Supports frontend and backend analysis workflow

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js
- Puppeteer

## Running the Project

Clone the repository:

```bash
git clone https://github.com/techiesrishti/webslim.git
```

Install dependencies:

```bash
cd frontend
npm install

cd ../backend
npm install
```

Start the project:

```bash
npm start
```
